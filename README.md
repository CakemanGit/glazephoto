# GlazePhoto

**Высокопроизводительный веб-редактор растровой графики в стиле Aero, построенный на TypeScript и .NET по методологии Clean-Room Design.**

> **Статус проекта:** активная разработка. Интерфейс, инструменты, история, фоновые вычисления и API-компоненты находятся на разных этапах интеграции.
>
> **Версия .NET:** в текущих файлах проектов указан `net10.0`, а не .NET 8. До обновления конфигурации запускайте проект на .NET 10 SDK. Описание стека ниже отражает фактические project-файлы репозитория.

GlazePhoto — браузерный редактор растровых изображений. Проект сочетает стеклянный интерфейс Aero с модульной архитектурой на TypeScript, Web Workers и ASP.NET Core. Серверная часть использует ImageSharp для разбора и преобразования изображений.

## Возможности

- Aero-интерфейс с панелями слоёв, истории, параметрами кисти и центральной рабочей областью.
- Модель слоёв с прозрачностью, видимостью, режимами наложения и смещением.
- Инструменты кисти, ластика, перемещения, масштабирования и панорамирования.
- История undo/redo со снимками пикселей и ограниченной глубиной.
- Фоновое попиксельное смешивание слоёв через Web Worker.
- API для обработки изображений: негатив и Gaussian blur.
- Экспорт сессии в ZIP и сведённого изображения в PNG/JPEG.
- SIMD-ориентированные операции и параллельная обработка пикселей на сервере.

Некоторые части интерфейса пока являются демонстрационными и не связаны со всеми движками редактирования. Перед использованием как полноценного редактора проверяйте фактическую интеграцию конкретного инструмента или экспортного сценария.

## Технологический стек

### Фронтенд

- TypeScript 5
- React 18
- Vite 5
- HTML Canvas API и HTML5 Web Workers
- `lucide-react` для иконок
- CSS с `backdrop-filter`, стеклянными слоями, бликами и адаптивной компоновкой

### Бэкенд

- ASP.NET Core Web API
- Целевая платформа в репозитории: `.NET 10` (`backend/backend.csproj`)
- ImageSharp 4 для чтения, преобразования и кодирования изображений
- Swashbuckle.AspNetCore для Swagger UI в проекте `backend`
- `System.Numerics` и `Parallel.For` для векторных и параллельных вычислений

В репозитории также есть корневой `GlazeApi.csproj`. Для локального запуска API используйте отдельный проект `backend/backend.csproj`: он содержит текущую конфигурацию Swagger и серверную точку входа.

## Быстрый локальный запуск

Запустите фронтенд и бэкенд в отдельных терминалах из корня репозитория.

### 1. Фронтенд

```bash
pnpm install
pnpm dev
```

Откройте адрес, указанный Vite (обычно `http://localhost:5173`).

Для сборки фронтенд-бандла без отдельной проверки типов:

```bash
pnpm exec vite build
```

В `package.json` команда `pnpm build` запускает `tsc && vite build`, однако в репозитории пока нет `tsconfig.json`; поэтому стандартная команда завершится сообщением справки TypeScript. Для полноценного `pnpm build` необходимо добавить конфигурацию TypeScript.

### 2. API-сервер

Для PowerShell:

```powershell
$env:ASPNETCORE_ENVIRONMENT = "Development"
dotnet watch run --project backend\backend.csproj --no-launch-profile -- --urls http://localhost:5097
```

Для Bash:

```bash
ASPNETCORE_ENVIRONMENT=Development dotnet watch run --project backend/backend.csproj --no-launch-profile -- --urls http://localhost:5097
```

При запуске в Development Swagger UI доступен по адресу:

```text
http://localhost:5097/swagger
```

Политика CORS бэкенда разрешает origin `http://localhost:5173`. Фронтенд-сервис обработки изображений настроен на API по адресу `http://localhost:5097`.

Если зависимости .NET ещё не восстановлены:

```bash
dotnet restore backend/backend.csproj
```

Сборка серверного проекта:

```bash
dotnet build backend/backend.csproj
```

## API

Текущие маршруты `ImageProcessingController`:

| Метод | Маршрут | Назначение |
|---|---|---|
| `POST` | `/api/ImageProcessing/ProcessImage` | Принимает multipart-поля `image` и `filterType`; поддерживаемые фильтры: `negative`, `gaussian-blur`; возвращает PNG |
| `POST` | `/api/ImageProcessing/Export/Session` | Принимает метаданные проекта и байтовые данные слоёв, возвращает ZIP-архив |
| `POST` | `/api/ImageProcessing/Export/Flattened?format=png` | Возвращает сведённый PNG |
| `POST` | `/api/ImageProcessing/Export/Flattened?format=jpeg` | Возвращает сведённый JPEG |

Swagger UI в Development можно использовать для просмотра схемы запросов и ручной проверки endpoints. Для сведения экспортер в текущей реализации поддерживает только режим наложения `normal`.
